# 图标来源与版权

本项目首页使用的图标来自 Twemoji 项目。

## 来源

- 项目: Twemoji (Twitter Emoji)
- 仓库: https://github.com/twitter/twemoji
- 版本: v14.0.2
- CDN: https://cdn.jsdelivr.net/gh/twitter/twemoji@14.0.2/assets/svg/

## 使用的图标

| 文件名 | Emoji | 用途 | Unicode |
|--------|-------|------|---------|
| disc.svg | 💿 | 系统下载 (ISO) | U+1F4BF |
| package.svg | 📦 | 软件源 | U+1F4E6 |
| whale.svg | 🐳 | 容器镜像 | U+1F433 |
| folder.svg | 📁 | 软件包 | U+1F4C1 |
| warning.svg | ⚠️ | 警告提示 | U+26A0 |
| penguin.svg | 🐧 | 操作系统默认图标 | U+1F427 |

## 替换原因

原始项目使用 Unicode emoji 字符作为图标，在未安装 emoji 字体（如 Noto Color Emoji）的系统上无法显示。替换为 SVG 图片后可确保所有用户都能正常查看图标。
